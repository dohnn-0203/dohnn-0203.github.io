# 김도현의 Unity 개발 포트폴리오

공개 사이트: [dohnn-0203.github.io](https://dohnn-0203.github.io/)

이력서와 함께 전달하는 Unity와 C# 개발 포트폴리오입니다. 산업용 3D 시뮬레이션, 렌더링 최적화, 실시간 데이터 연동, 데스크톱 뷰어 개발에서 맡은 기능과 구현 방법을 설명합니다.

## 구성

- 프로필과 연락처
- Unity, C# 주요 실무 프로젝트 2개
- WebGL Playground와 Chess 개인 프로젝트
- 웹 프론트엔드, 데이터 시각화 실무 경험 2개
- 경력, 학력, 기술, 개발자로서의 관점

프로젝트의 주요 기여는 기본 화면에 표시됩니다. 상세 구현은 펼쳐볼 수 있고, 화면 이미지는 클릭하면 확대됩니다. 모바일 레이아웃과 인쇄 스타일을 포함합니다.

## 실행과 배포

HTML, CSS, JavaScript 정적 사이트로, 패키지 설치나 빌드가 필요하지 않습니다. `index.html`을 열거나 아래 명령으로 로컬 서버를 실행합니다.

```sh
python -m http.server 8000
```

GitHub Pages는 `main` 브랜치의 `/(root)`를 게시합니다. 해당 브랜치에 커밋하면 사이트가 다시 배포됩니다. `.nojekyll` 파일을 유지하세요.

## 수정 위치

| 파일 | 내용 |

이메일 수정 시 화면 주소, `mailto:` 링크, 복사 버튼의 `data-email`을 함께 변경하세요. GitHub 프로젝트 사이트 하위 경로에 복제할 경우 `og:image`의 절대 주소도 해당 경로에 맞춰 변경해야 합니다.

상단의 `이력서 다운로드`는 같은 사이트에 보관한 PDF를 `김도현_이력서.pdf` 이름으로 저장합니다. 이력서를 갱신할 때는 `assets/kim-dohyeon-resume.pdf`를 새 파일로 교체하면 됩니다.

## 페이지 안에서 체스 플레이

개인 프로젝트의 Chess 항목에서 `이 페이지에서 플레이`를 누르면 같은 페이지 안에 게임 화면이 열립니다. 이때 `games/chess/`를 iframe으로 불러오며, 포트폴리오 페이지 주소는 바뀌지 않습니다. 실행 전에는 WebGL 파일을 요청하지 않습니다.

`전체화면`은 브라우저가 지원하는 경우 게임 영역을 확대합니다. `게임 닫기`는 iframe을 제거해 게임을 종료하고 실행 버튼으로 포커스를 돌려줍니다. 닫거나 다시 불러오면 진행 중인 대국은 초기화됩니다. PC에서 마우스로 플레이하는 것을 권장합니다.

게임은 원래 장면의 원근 카메라와 배경을 사용하고 최근 게임 로그 3줄을 표시합니다. 게임 안의 `Menu`를 열면 전체 이동 기록과 잡은 말을 확인할 수 있습니다. 새 게임, 기권, 시점 전환, 무승부 청구도 이 메뉴에서 이용하며, 승급 선택과 대국 종료 안내는 별도 창으로 표시합니다.

게임 실행 페이지는 부모 페이지에 `chess-player-progress`, `chess-player-ready`, `chess-player-error` 메시지를 보냅니다. 부모 페이지는 같은 출처의 현재 게임 iframe에서 온 메시지만 처리합니다. 파일을 불러오지 못하거나 준비 메시지를 2분 동안 받지 못하면 다시 불러오기 버튼을 제공합니다.

체스 빌드를 갱신할 때는 `games/chess/Build/`와 `games/chess/build-config.json`을 함께 교체하고, 설정의 파일명이 새 빌드와 일치하는지 확인하세요. `games/chess/index.html`, `player.js`, `player.css`는 포트폴리오 연동과 로딩 처리를 담당하므로 유지합니다. 실제 WebGL 실행 확인에는 HTTP 서버가 필요하므로 `file://` 방식 대신 위의 로컬 서버나 GitHub Pages 주소를 사용합니다.

게시된 WebGL은 Unity 2022.3.62f3의 Release 빌드입니다. gzip 압축과 Decompression Fallback을 사용하며 WebGL 스레드는 비활성화했습니다. Unity 2023을 지정한 Chess 원본 프로젝트와 분리한 빌드용 복사본에서 생성했습니다.

## 자료와 라이선스

업무 프로젝트 설명과 화면은 김도현의 이력서, 포트폴리오 자료를 바탕으로 작성했습니다. 개인 프로젝트는 연결된 GitHub 저장소의 공개 구현을 기준으로 정리했습니다. 입사 월이 자료마다 달라 경력에는 확인 가능한 `2023년 입사`를 표시했습니다.

프로젝트 설명은 실제 개발한 기능과 구현 과정을 완전한 문장으로 풀어 썼습니다. 가운데점과 화살표를 사용하지 않으며, 담당 범위와 자료 작성 당시의 진행 상태를 구분합니다.

상세 주소, 생년월일, 전화번호와 원본 PDF는 게시 파일에 포함하지 않았습니다. 공개 연락처는 이메일을 사용합니다.

Pretendard 가변 글꼴은 자체 포함하며, SIL Open Font License는 `assets/Pretendard-LICENSE.txt`에 있습니다. 외부 CDN이나 API 키가 필요하지 않습니다.
