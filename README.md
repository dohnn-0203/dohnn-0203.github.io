# 김도현 · Unity / C# 포트폴리오

공개 사이트: [dohnn-0203.github.io](https://dohnn-0203.github.io/)

이력서와 함께 전달하는 Unity·C# 개발 포트폴리오. 산업용 3D 시뮬레이션, 렌더링 최적화, 실시간 데이터 연동, WinForms–Unity 통합 경험을 담당 역할·구현·결과로 정리했습니다.

## 구성

- 프로필과 연락처
- Unity·C# 주요 실무 프로젝트 2개
- WebGL Playground와 Chess 개인 프로젝트
- 웹 프론트엔드·데이터 시각화 실무 경험 2개
- 경력·학력, 기술, 개발자로서의 관점

프로젝트의 주요 기여는 기본 화면에 표시됩니다. 상세 구현은 펼쳐볼 수 있고, 화면 이미지는 클릭하면 확대됩니다. 모바일 레이아웃과 인쇄 스타일을 포함합니다.

## 실행과 배포

HTML·CSS·JavaScript 정적 사이트로, 패키지 설치나 빌드가 필요하지 않습니다. `index.html`을 열거나 아래 명령으로 로컬 서버를 실행합니다.

```sh
python -m http.server 8000
```

GitHub Pages는 `main` 브랜치의 `/(root)`를 게시합니다. 해당 브랜치에 커밋하면 사이트가 다시 배포됩니다. `.nojekyll` 파일을 유지하세요.

## 수정 위치

| 파일 | 내용 |
| --- | --- |
| `index.html` | 프로필, 프로젝트, 경력, 기술, 연락처 |
| `styles.css` | 글꼴, 색상, 문서 레이아웃, 반응형·인쇄 스타일 |
| `app.js` | 이미지 확대, 이메일 복사, 목차의 현재 위치 표시 |
| `assets/` | 프로젝트 화면, 글꼴, 아이콘 |

이메일 수정 시 화면 주소, `mailto:` 링크, 복사 버튼의 `data-email`을 함께 변경하세요. GitHub 프로젝트 사이트 하위 경로에 복제할 경우 `og:image`의 절대 주소도 해당 경로에 맞춰 변경해야 합니다.

상세 주소·생년월일·전화번호와 원본 PDF는 게시 파일에 포함하지 않았습니다. 공개 연락처는 이메일을 사용합니다.
